# Alpha Sales intake-record flow

Interactive frontend prototype covering:

- Intake list and record details
- Pending → Assigned → In Progress status transitions
- Demo scheduling
- Deal creation and linked pipeline details
- Inline prospect rejection

## Run locally

Open `index.html` in a browser. For the most reliable result, serve this folder with a simple local web server.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the complete `assets` folder to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/(root)` folder, then click **Save**.
7. Wait for GitHub to display the published site URL.

The prototype is static and does not require a backend or build process.
